# 🐧 Administration Système & Durcissement Linux Ubuntu

Ce projet rassemble une série d'exercices pratiques axés sur l'administration système, la gestion des utilisateurs et le contrôle d'accès sous l'environnement **Linux Ubuntu Server**.

---

## 📌 Objectifs & Modules Pratiques
- **Gestion des Utilisateurs & Groupes :** Création de comptes d'utilisateurs (`alice`, `bob`, `charlie`), attribution de shells sécurisés (`/bin/bash`) et structuration des groupes (`devweb`).
- **Sécurité & Contrôle d'Accès :** Application du principe du moindre privilège via les permissions Linux standard (`chmod`, `chown`) et avancées (`setfacl`).
- **Gestion des Politiques de Mots de Passe :** Configuration de l'expiration et du cycle de vie des comptes via `chage`.

---

## 🛠️ Commandes & Outils Utilisés
- **Gestion des comptes :** `useradd`, `usermod`, `groupadd`, `chage`
- **Droits & ACLs :** `chmod`, `chown`, `getfacl`, `setfacl`
- **OS de laboratoire :** Linux Ubuntu Server / VMware
